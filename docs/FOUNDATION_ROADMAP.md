# MOXIE Foundation Roadmap

## Phase 0 — Foundation
- Product charter and governance
- Repository isolation and branch policy
- Historical reference boundary
- Domain specialist registry
- Architecture decision record set
- Test strategy and evidence model

## Phase 1 — Intelligence Core
- Trend signal ingestion and normalization
- Opportunity scoring
- Audience/competitor context
- Brand Brain / Knowledge context
- Research and evidence store

## Phase 2 — Agent & Workflow Core
- Agent contract and registry
- Workflow planner
- Runtime routing
- Tool/connector abstraction
- Human approval and autonomy gates
- Full traceability of agent decisions

## Phase 3 — Content Factory
- Strategy generation
- Hooks, titles, captions, scripts and long-form drafts
- Image/creative briefs
- Video planning and production pipeline
- Channel-specific adaptation
- Originality, factual and brand QA

## Phase 4 — Publishing & Calendar
- Social/channel connector layer
- Scheduling and approval queues
- Publishing policy engine
- Retry, idempotency and audit logs
- L0–L3 autonomy production qualification

## Phase 5 — Analytics & Growth Loop
- Cross-channel performance ingestion
- Content and audience analytics
- Experimentation and A/B testing
- Winning-pattern extraction
- Recommendation feedback loop

## Phase 6 — Paid Media Intelligence
- Promotion candidate detection
- Ad creative variants
- Audience/campaign recommendations
- Authorized paid-media activation
- CTR/CPA/ROAS learning loop

## Phase 7 — Controlled Autonomous Growth
- L4 scheduled autonomy
- Bounded L5 closed-loop workflows
- Policy/compliance guardrails
- Portfolio-level growth intelligence

## First executable vertical slice

**Trend Opportunity → Research → Content Brief → QA → Human Approval Queue**

The first slice deliberately stops before automated publishing. It proves the intelligence, workflow, traceability, brand-aware generation and approval architecture before channel-write permissions are introduced.
