# MOXIE

**AI Content Intelligence & Growth Automation Platform**

MOXIE is a RAMTech Solutions product focused on discovering content opportunities, understanding why they matter, creating original channel-ready content, publishing through controlled authority, measuring outcomes, and continuously improving strategy.

## Product loop

Discover → Understand → Strategize → Create → Validate → Publish through Authorized Capability → Measure → Learn → Improve

## Project status

MOXIE is a greenfield rebuild informed by the historical AI Intelligence Platform / AI Agent Workflow Analysis project. Historical code and build artifacts are reference material, not the protected implementation baseline.

MOXIE remains gated from live agent execution until the applicable RVSC sandbox, filesystem, OS/process, transport, transitive-egress, credential, broker, monitoring, and independent qualification requirements pass.

## Governance

This repository is managed under the RAMTech Virtual Software Company (RVSC) operating model and adopts the authoritative RVSC Constitution through `governance/RVSC_GOVERNANCE.md`.

Product development proceeds through bounded work packages, isolated assigned workspaces, controlled branches, independent QA, evidence-backed review, fail-closed security, no direct/transitive agent egress, and governed human-gated release/publishing authority.

MOXIE may improve its strategies and capabilities, but greater intelligence or performance never grants additional authority.
